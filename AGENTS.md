# Repository Guidelines

## Project Overview

AI-Exercise-Assistant is an exercise-focused assistant project. Keep repository documentation and implementation changes clear, focused, and easy to extend.

## Development Workflow

- Inspect the existing repository structure before making changes.
- Keep changes small and scoped to the requested work.
- Preserve user-authored changes and avoid rewriting unrelated files.
- Add or update documentation when behavior or setup changes.

## Validation

Run the project's documented tests, linters, and build commands when they are available. If no project tooling exists, state that clearly rather than introducing new tooling solely for validation.
